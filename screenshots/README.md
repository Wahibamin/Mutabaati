# الصور الأصلية للتوثيق — مقوتي

هذه الصور العشر التُقطت فعليًا من النسخة المتقدمة للتطبيق على هاتف Android، ثم اقتصرت المعالجة على:

- إزالة شريط عنوان عارض الهاتف في Windows وشريط التنقل الأسود السفلي.
- إخفاء معلومات تعريفية وأسماء وأرقام اتصال وأرصدة مختارة، باستبدال مواضعها بلون معتم غير قابل لاسترجاع النص الأصلي.
- إنشاء لوحة تجميع `00-gallery.png` من خمس صور حقيقية.

لا توجد صور مصطنعة، ولا تُرفق النسخ الشخصية الأصلية داخل مستودع GitHub.
