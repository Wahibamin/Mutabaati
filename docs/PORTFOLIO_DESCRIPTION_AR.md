# نصوص جاهزة لملف التوظيف

## وصف قصير للمستودع

مقوتي | تطبيق محاسبي عربي باستخدام Flutter وDrift/SQLite لإدارة البيع والشراء والذمم والمخزون والمصاريف، مع تقارير محلية ودعم العمل دون إنترنت.

## وصف للسيرة الذاتية

**مقوتي (Flutter / Dart / Riverpod / SQLite):** تطوير تطبيق محاسبي عربي متخصص لإدارة المبيعات والمشتريات وحسابات الموردين والزبائن. تصميم تدفقات مخزون وتكلفة بضاعة مباعة (COGS) ومرتجعات، وترحيل قاعدة بيانات محلية دون حذف بيانات سابقة، مع اختبارات محاسبية آلية وواجهات RTL.

## عرض شفهي مختصر في مقابلة

«طوّرت مقوتي لتبسيط المعاملات اليومية للبائعين في بيئة لا يتوفر فيها الإنترنت بشكل دائم. اعتمدت Flutter وRiverpod للواجهة والحالة، وDrift/SQLite لتخزين الحركات محليًا. ركزت على التمييز بين الربح والسيولة، وحساب COGS، وضبط المرتجعات والديون، ثم أضفت اختبارات للمعاملات والترحيل والاستعادة. ما زلت أتعامل معه كنموذج متقدم يحتاج اختبار استخدام أوسع قبل إطلاقه التجاري».

**المطور:** وهيب الكبودي.
