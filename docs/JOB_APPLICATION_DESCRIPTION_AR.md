# وصف «متابعتي» للتوظيف والسيرة الذاتية

**المطور: وهيب الكبودي | Flutter Developer**

## وصف قصير لمستودع GitHub

تطبيق Flutter عربي لتنظيم الحياة اليومية دون إنترنت، يجمع متابعة العادات والصلوات والمصاريف والمهام والمواعيد وتقارير الإنجاز، مع تخزين محلي باستخدام Drift/SQLite.

## وصف للسيرة الذاتية

**متابعتي (Mutabaati) — تطبيق تنظيم شخصي لأندرويد**  
طوّرت تطبيق Flutter عربيًا متعدد الوحدات لإدارة المتابعة اليومية وتسجيل الصلوات والمصاريف والمهام والمواعيد، مع تقارير أسبوعية وشهرية. استخدمت Riverpod لإدارة الحالة، وDrift/SQLite للتخزين المحلي، وgo_router للتنقل، مع فصل طبقات البيانات عن واجهات المستخدم وبناء واجهة RTL مناسبة للمستخدم العربي.

## فقرة تعريفية للمقابلة التقنية

«متابعتي» مشروع ركزت فيه على بناء تطبيق شخصي مفيد دون الاعتماد على اتصال بالشبكة. بدأت بتنظيم البيانات الخاصة بكل وظيفة، ثم ربطتها بواجهات Flutter عبر Riverpod ومستودعات Drift. التحدي الأساسي كان اختلاف طبيعة البيانات بين الصلوات والعادات الدورية والمصروفات والمهام؛ لذلك فصلت الوحدات البرمجية وخصصت نماذج للتواريخ والتكرار والحفظ. يتيح التطبيق للمستخدم متابعة يومه والاطلاع على تقارير، وتوثّق الصور تشغيل واجهاته على Android. لا تزال تجربة التنبيهات في الخلفية والنسخ الاحتياطي عبر منتقي الملفات من النقاط التي أعتزم اختبارها وتحسينها قبل أي إطلاق إنتاجي.»

## مهارات يظهرها المشروع

- تصميم تجربة استخدام عربية متعددة الصفحات باستخدام Flutter وMaterial 3.
- تخزين البيانات محليًا والاستعلام عنها باستخدام SQLite وDrift.
- إدارة الحالة باستخدام Riverpod.
- بناء مستودعات بيانات قابلة للفصل والاختبار.
- نمذجة أحداث متكررة وتواريخ وتقارير زمنية.
- تقديم مشروع GitHub موثّق بالصور مع بيان واضح لنطاق التحقق والقيود.

**تنبيه:** الأوصاف أعلاه تصف ما هو موجود في الكود والواجهات، ولا تزعم اجتياز اختبارات حالية أو إطلاق التطبيق على متجر التطبيقات.
