# دليل تشغيل ونشر متابعتي

## أولًا — التشغيل على جهاز المطور

1. افتح المجلد `Mutabaati/` الموجود في هذه الحزمة، وليس مجلد `musim` الافتراضي القديم.
2. تحقق من بيئة Flutter وAndroid SDK:

```bash
flutter doctor
```

3. استرجع الاعتماديات ثم شغّل التطبيق:

```bash
flutter pub get
flutter run
```

4. عند وجود الحزم محليًا يمكن تجربة `flutter run --no-pub`. تنبيه: Gradle قد يحتاج تحميل مكتبات Android حتى مع هذا الخيار.
5. لتشغيل الاختبارات المحلية:

```bash
flutter analyze
flutter test
```

لم يتم تنفيذ هذه الأوامر من طرف مُعد الحزمة على جهاز Windows الفعلي. يرجى مراجعة النتائج بنفسك إن أردت إثبات تشغيل حديث.

## ثانيًا — النشر على GitHub

1. أنشئ مستودعًا جديدًا باسم مقترح: `mutabaati-flutter`.
2. فك ضغط `Mutabaati_GitHub_Portfolio_AR.zip`.
3. ارفع **محتويات مجلد `Mutabaati`** إلى جذر المستودع: `README.md` و`lib` و`android` و`test` و`docs` و`screenshots` و`pubspec.yaml` و`pubspec.lock`.
4. لا ترفع ملف ZIP بدل ملفات المصدر.
5. اجعل وصف المستودع: `تطبيق Flutter عربي لمتابعة العادات والصلوات والمصاريف والمهام دون إنترنت | Arabic Offline Personal Tracker`.
6. تأكد من ظهور صورة المعرض في أعلى README وروابط الصور العشر.
7. أبق ملفات التوقيع، وقواعد البيانات الفعلية، والنسخ الاحتياطية الخاصة خارج المستودع.

## الترخيص

لم يُضف ترخيص مفتوح المصدر تلقائيًا؛ إذا رغبت في السماح للغير بإعادة استخدام الكود فاختر الترخيص بنفسك بعد مراجعة حقوق المشروع والمكتبات الخارجية.
