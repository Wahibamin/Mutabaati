## قيود يجب الإفصاح عنها

- بعض ميزات الإقفال اليومي المعتمد على عد نقدي فعلي لم تكتمل، رغم وجود ملخصات.
- لا يوجد تدفق متكامل لعكس كل أنواع الحركات المحاسبية من الواجهة.
- البيانات القديمة ناقصة التكلفة تُوسم `UNKNOWN`، ولا توجد إعادة تشغيل مؤرخة للخلف.
- تبقى بعض الحقول المالية بنوع `REAL` للتوافق مع البنية القديمة.
- توقيع `release` الحالي يعتمد إعداد Debug في المشروع، وليس صالحًا كعملية إطلاق إنتاجية موثوقة.
- تكامل النسخ السحابي والبصمة يحتاجان اختبارًا يدويًا على جهاز فعلي.

## أوامر إعادة التحقق محليًا

```bash
flutter pub get
flutter analyze
flutter test test/maqwati_accounting_test.dart test/accounting_modernization_test.dart
flutter build apk --debug
```
