# دليل صور واجهات مقوتي

جرى بالفعل توثيق **10 شاشات حقيقية** داخل `screenshots/`، بالإضافة إلى معرض مصغر `00-gallery.png`. لا حاجة إلى إعادة تصوير الواجهات للتوثيق الحالي.

لأي نشر لاحق، استخدم بيانات عرض تجريبية وتجنب نشر أسماء العملاء والموردين وأرقام التواصل والأرصدة. تم حجب البيانات الحساسة المحددة في الصور المرفقة، لكن راجع لقطات جديدة قبل إضافتها.

تُعرض جميع الصور وروابطها مباشرة داخل `README.md` بصيغة Markdown القياسية.
